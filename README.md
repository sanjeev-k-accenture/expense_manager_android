# Expense Manager

## Features

1. Transaction

### 1. TRANSACTION

Add insert and show transactions along with sum of the transactions till now.

There will be two screens:

1. Insert Transaction Screen: `TransactionFormScreen`
2. All transactions screen (history): `TransactionsHomeScreen`<br> This screen will have a button or
   CTA for going into the `TransactionFormScreen`
3. The `TransactionsHomeScreen` shows total debit and total credit as well.

### 2. CATEGORY

1. Transaction list and detail we can show the category
2. In the transaction form we can receive all the categories the user has created and display on a
   dropdown for him to select.
3. Create an update transaction page. Currently only delete button is there, we can add update
   button as well in transaction detail.
4. For update transaction, we can navigate to TransactionFormScreen itself with values filled. So
   navigation exercise.
