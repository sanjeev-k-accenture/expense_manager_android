# Expense Manager

## Features

1. Transaction

### 1. TRANSACTION

Add insert and show transactions along with sum of the transactions till now.

There will be two screens:

1. Insert Transaction Screen: `TransactionFormScreen`
2. All transactions screen (history): `TransactionsHomeScreen` - This screen will have a button or
   CTA for going into the `TransactionFormScreen`
3. Transaction detail screen: `TransactionDetailScreen` - This screen will have a button to delete
   that transaction.
